## 👋 Hi, I'm Allan Pereira Fenelon

I'm a **Data Scientist** and **Computational Mathematician** from Juazeiro do Norte, Ceará, Brazil. I build **machine learning models**, **LLM-powered applications** and **data pipelines** that run in production, not just in notebooks.

My work spans **predictive modeling** (classification, propensity and **time series forecasting**), **Bayesian statistics**, **MLOps**, and **Generative AI** with **LangChain**, **LangGraph** and **FastAPI**. I enjoy turning messy, large-scale data into decisions that matter for energy, public health and government.
